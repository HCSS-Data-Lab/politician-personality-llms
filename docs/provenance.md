# Provenance and scope

The statistical functions are adapted from the executed study's scoring and analysis code. Historical orchestration notes, private paths and unused command-line entry points have been removed. Speech-model contrast arithmetic is batched while retaining the original per-world random-number draws; both scalar-equivalence tests and all 1,320 frozen contrast rows verify numerical parity. `pinf/instrument.py` retains the executed item wording, label bindings, within-battery display ordering, framing scaffolds and JSON schemas. The public framing names `E`, `neutral`, `P` correspond to the original internal codes `G`, `O`, `K`.

`records/ratings.jsonl` is a field-allowlisted export of successful model responses, not an export of request caches. Identity-baseline responses are associated with each politician even where an identical request was shared. The file contains 29,625 records: 9,135 name-context; 3,045 name-only; 3,045 context-only; 8,640 named-speech; 5,760 anon-speech. The speech arms use 192 speeches from 50 politicians, and the identity arms use 203 politicians. All five models and all executed framings are included. No unexecuted condition/framing combination is filled in.

`records/recognition.jsonl` contains 960 model guesses and their automatic and audited labels. `manifests/recognition_corrections.csv` lists the 52 changed labels within this analysis sample. The original broader audit had one further correction outside this sample. These are scoring corrections to model guesses, not changes to expert personality ratings. They must never be applied to newly generated guesses merely because a model and speech ID match.

The membership list preserves the exact analysis sample. Membership was determined from individual expert item coverage supplied privately; those responses and their per-item counts are excluded. The candidate-election IDs permit public-data reconstruction of the criterion for the fixed sample, but cannot independently re-establish the original inclusion decision.

The release includes authored code, prompts, selection/transformation metadata, model-generated responses, aggregate statistical outputs, and the explicitly approved eight-column public Wikimedia prominence snapshot in `measurements/prominence_2026-07-06.csv`. That snapshot contains only public source identifiers, dates, and counts, reused under CC0; see [prominence.md](prominence.md). It excludes source transcripts, expert responses, candidate-level expert criterion values, private review materials, account configuration and request/response caches. Downloaded datasets and generated criterion tables belong under ignored `data/` and must not be included in a release archive. Prompt/questionnaire wording is attributed to the instruments described in the paper, including TIPI (Gosling et al., 2003) and the NEGex questionnaire; this package does not grant rights over third-party instruments or datasets.

The MIT license covers our software. External data and model checkpoints remain subject to their original terms. Model responses are experimental observations about model behavior, not clinical assessments or established facts about named politicians. Intended use is research into model behavior and agreement with expert perceptions; these records should not be used to screen or make decisions about people.

Publication files are enumerated by relative path, size and SHA-256 in `RELEASE_MANIFEST.json`. Packaging must follow this allowlist. A static audit is supplemented by schema, coverage, adversarial leakage, numerical reproduction and runner tests.
